# MangaPark Image Fixer Extension
Fixes broken manga images by testing all MangaPark domains and servers automatically.

--------------------------------------------
📌 IMPORTANT NOTE ABOUT PAGE REFRESH
--------------------------------------------
After installing the extension:

✔ When you open a MangaPark chapter,  
   the extension will fix the image links.

✔ Sometimes you need to **refresh the page once**
   for the fixed images to fully load.

This is normal because MangaPark loads images dynamically.

--------------------------------------------
📌 HOW TO INSTALL (PC – Windows / Mac / Linux)
--------------------------------------------

### GOOGLE CHROME / BRAVE / EDGE
1. Download the ZIP file: mangapark_image_fixer_full.zip
2. Extract the ZIP to any folder.
3. Open your browser.
4. Go to:
   chrome://extensions/
5. Turn ON “Developer mode”.
6. Click “Load unpacked”.
7. Select the extracted folder.
8. Open MangaPark → If images do not appear, refresh once.

--------------------------------------------
📌 HOW TO INSTALL ON ANDROID
--------------------------------------------

Chrome on Android DOES NOT support extensions.
You must use a browser that supports Chrome extensions.

### KIWI BROWSER (100% working)
1. Install “Kiwi Browser” from Play Store.
2. Tap ⋮ → Extensions.
3. Turn ON “Developer mode”.
4. Tap “Load”.
5. Select the extracted extension folder.
6. Open MangaPark → Refresh once if images still missing.

### YANDEX BROWSER (partial support)
If loading the extension fails, use Kiwi instead.

--------------------------------------------
📌 HOW TO INSTALL ON iOS (iPhone / iPad)
--------------------------------------------

Chrome / Firefox / Safari on iOS cannot load extensions.

### ORION BROWSER (supports Chrome extensions)
1. Install “Orion Browser” from App Store.
2. Visit:
   orion://extensions
3. Turn ON “Developer Mode”.
4. Tap “Load Unpacked Extension”.
5. Choose the extracted extension folder.
6. Open MangaPark → Refresh once to load fixed images.

### If Orion fails:
- Use MangaPark “Download View” as fallback.
- Or use Android with Kiwi Browser for full support.

--------------------------------------------
📌 NOTES
--------------------------------------------
- Only PC browsers, Android (Kiwi), and iOS (Orion) can run Chrome extensions.
- Chrome Mobile and Safari Mobile cannot install extensions.
- If images still look broken, try refreshing the page once.
